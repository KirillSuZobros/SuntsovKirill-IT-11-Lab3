## Задание 2
### Задача 2
#### Текст задачи
Секреты. 
Секреты никому нельзя рассказывать. Никому кроме одного самого близкого друга! Необходимо 
описать сущность Секрет, которая будет позволять хранить и передавать некоторый текст только 
одному другому хранителю.   
Состояние сущности описывают следующие сведения:    
• Текст секрета, в виде строки.   
• Имя хранителя секрета, в виде строки   
Инициализация сущности может быть выполнена следующим образом:   
• С указанием имени хранителя секрета и текста секрета, это будет означать создание 
нового секрета.   
• С указанием другого Секрета и именем хранителя секрета. В этом случае мы считаем, что 
секрет был рассказан другому человеку. При передаче секрета должно произойти 
следующее: во-первых, на консоль выводится текст вида “Имя сказал что Секрет”, где Имя 
и Секрет представляют собой имя того кто рассказывает секрет и текст секрета 
соответственно. Во-вторых, текст секрета у нового хранителя должен представлять собой 
копию текста предыдущего хранителя, но с добавлением Х случайных символов в Х 
случайных мест, где Х — это число в диапазоне от 0 до N, а Nв свою очередь это 10% от 
размера исходного текста. 
Поведение сущности описывают следующие действия:   
• Может быть приведен к строке, строковое преставление вида“Имя: это секрет!”, где Имя – 
это конкретное имя хранителя секрета, а остальное простой текст.   
• Можно узнать каким по очереди был данных хранитель секрета.   
• Можно узнать сколько еще человек узнали секрет после текущего хранителя.   
• Можно получить имя N-го человек узнавшего секрет, причем N будет положительным для 
случая, когда мы хотим узнать имя следующего узнавшего секрет, и отрицательным если 
предыдущего.     
• Можно узнать разницу в количестве символов текста секрета с N-ым человеком 
Необходимо учесть следующие требования к инкапсуляции:   
• Единственным способом получить текст секрета может быт его вывод на экран при 
инициализации объекта.   
• Секрет может быть передан только одному другому человеку и не должно быть способа 
рассказать один и тот же секрет нескольким людям.   
Продемонстрируйте работоспособность решения на примерах.
#### Алгоритм решения
Класс `Secret` реализован по принципу двусвязного списка с приватными ссылками `prev` и `next`.   
Поле `text` не имеет геттера и выводится в консоль только внутри второго конструктора при передаче секрета.   
В конструкторе передачи секрета проверяется не был ли секрет уже передан `old_secret.next != null` - если секрет уже был передан ранее, выбрасывается `IllegalArgumentException`.   
Добавление случайного количесива букв в случайные места текста выполняется через `ThreadLocalRandom`: вычисляется N - 10% от длинны текста и X - от 0 до N, после чего в цикле в случайные позиции строки вставляются случайные буквы алфавита.   
Навигация по цепочке вперед и назад реализована сдвигом указателя `curr` по ссылкам `next` и `prev`.  
Для нахождения каким по очереди был данный хранитель секрета - `curr` идёт по `prev` пока не достигнет `null`.  
Для нахождения сколько еще человек узнали секрет после текущего хранителя - `curr` идёт по `next` пока не достигнет `null`.  
Для нахождения имени N-го человека узнавшего секрет, причем N будет положительным для случая, когда мы хотим узнать имя следующего узнавшего секрет, и отрицательным если предыдущего - `curr` идёт по `next`(Если N > 0) ИЛИ `curr` идёт по `prev`(Если N < 0) пока не достигнет `null` или N не станет равным 0 - если `curr` достиг `null`, то выбрасывается `IllegalArgumentException`, иначе возвращается имя `curr`.  
Для нахождения разницы в количестве символов текста секрета с N-ым человеком - `curr` идёт по `next`(Если N > 0) ИЛИ `curr` идёт по `prev`(Если N < 0) пока не достигнет `null` или N не станет равным 0 - если `curr` достиг `null`, то выбрасывается `IllegalArgumentException`, иначе возвращается разница длины текста `curr` и `this`.

Клонирование точки.    
Измените сущность Точка из 2.6.2. Переопределите метод клонирования, унаследованный от 
класса Object, таким образом, чтобы при его вызове возвращался новый объект Точки, значения

#### Алгоритм решения
Класс `Point` реализует интерфейс `Cloneable` (`implements Cloneable`).   
Метод `clone()` переопределен с модификатором `public` и типом возвращаемых данных `Point`.   
Внутри метода вызывается `super.clone()` в блоке `try catch` (с перехватом `CloneNotSupportedException`), что создает новый независимый экземпляр `Point` с идентичными значениями координат `X` и `Y`.
